# Quy Tắc Git Workflow

- Mỗi khi hoàn thành việc chỉnh sửa, cập nhật tính năng hoặc sửa lỗi trên dự án theo yêu cầu của người dùng, luôn chủ động tạo commit rõ ràng và push thẳng lên repository GitHub (`origin/main`).
